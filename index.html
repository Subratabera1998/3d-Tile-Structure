How to Use

Overview

This tool lets you create and edit an interactive 3D block structure, change block colours, select and group blocks, move them, view flattened layers, and export the current view as a PDF.

Dimensions

Enter the dimensions of the local Subsystems of A, B and C respectively at the bottom as n ⊗ m ⊗ r and click Apply. Each block is identified by the coordinates ABC.

Colours

Click a colour in the palette to make it the active painting colour. Hover over a block to preview that colour, then click the block to apply it. Click the active colour again to remove the colour selection and return to block-selection mode.

Add Colour

Click the + button beside the colour palette to open the colour picker. Choose a custom colour and add it to the palette.

Selecting and Deselecting Blocks

When no colour is active, click a block to select it. Click a selected block again to deselect it. Click additional blocks to select multiple blocks.

The ▦ Select All button selects all blocks, and can be used again to deselect them.

Double-click on white space in the 3D view to clear both the selected blocks and the active colour. The same action works on empty areas of the flattened view.

Group, Separate, Reverse and Free Move

⧉ Group: groups the selected blocks. Selecting a complete existing group and using the same button performs the corresponding ungroup action.

⤢ Separate: separates the selected blocks or groups.

↺ Reverse: reverses the separation of selected blocks or groups by returning them toward their original positions.

When a grouped block is painted, the colour is applied consistently to the whole group. The same group-wide behaviour is used in the 3D and flattened views.

Free Move: Turn on Free Move, select blocks, then drag the selected blocks or groups in the 3D view.

Flattened View

Click 🧊 to show or hide the flattened representation. Use A, B, or C to choose which coordinate is fixed. Use ↑ / ↓ to change the layer order.

Sync Between 3D Blocks and Flattened Tiles

Each flattened tile represents the 3D block with the same ABC block number. The two views are synchronized by block identity, not by the block's current 3D position.

Selecting a block in the 3D view highlights the matching flattened tile, and selecting a tile in the flattened view selects the same 3D block.

Painting or hovering a block in either view is reflected on the corresponding item in the other view. If a block is moved, separated, or grouped in 3D, its flattened tile remains at the position determined by its original ABC coordinates.

History Count

History Count determines how many previous actions are retained for Undo and Redo.

PDF Export

Download: Click this button and choose PNG or PDF. The PNG has a transparent background. Ctrl+S / Cmd+S opens Save As directly.

Fullscreen

⛶ opens the custom fullscreen view. × closes it.

Keyboard Shortcuts

  • Ctrl+S: Save As
  • Ctrl+Z: Undo
  • Ctrl+Y: Redo
  • Ctrl+G: Group selected blocks and groups, or Ungroup when exactly one complete group is selected
  • Ctrl+A: Select/deselect all
  • ↑ / ↓ / ← / →: Move the selected blocks or group one Free Move step in the corresponding screen direction
  • Esc: Exit
